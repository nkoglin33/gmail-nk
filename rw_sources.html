Methodology
This report is produced by a scheduled AI research agent and represents live web research, not a Bloomberg/FactSet-certified institutional data pull. All figures should be spot-checked before board-level or investor-facing use. The agent runs each Monday morning and covers the calendar week just ended (prior Monday–Friday). Operating metrics are sourced directly from company earnings press releases and investor supplementals. Price data is pulled from the Yahoo Finance chart API when accessible; when blocked (as in this cycle), the report uses the most recent committed rw_prices.json snapshot from the GitHub Actions workflow, clearly labeled with its as-of date.
