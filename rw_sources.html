Methodology
This report is produced through live web research (company IR sites, press-release aggregators, and sell-side commentary) and is not a Bloomberg/FactSet-certified data pull. All figures should be spot-checked before board-level or investment-committee use. Operating metrics are sourced from company earnings releases and supplemental filings; prices from Yahoo Finance chart API via the GitHub Actions snapshot (see below). Any figures marked "est." are estimates and should be verified against the underlying source before reliance.
