Methodology
This report is produced by live web research and structured data from a GitHub Actions price snapshot. It is not a Bloomberg or FactSet-certified data pull. Hard numbers (price, return, rent spreads, occupancy, guidance) are sourced directly from company IR pages, SEC filings (8-K / earnings releases), and the Yahoo Finance chart API via a scheduled GitHub Actions workflow. Sector narrative and sell-side commentary are sourced from web research (Seeking Alpha, Nareit, sell-side summaries, press releases). Spot-check against primary sources before board-level use.

REG, BRX, KIM, FRT, AKR, UE, and CURB do not separately quantify escalators in public filings. This is a known standard-practice gap, not a research failure.
