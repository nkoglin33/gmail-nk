Methodology
This report is produced by a scheduled AI research agent and represents live web research, not a Bloomberg/FactSet-certified institutional data pull. All figures should be spot-checked before board-level or investor-facing use. The agent runs each Monday morning and covers the calendar week just ended (prior Monday–Friday). Operating metrics are sourced directly from company earnings press releases and investor supplementals. Price data is pulled from the Yahoo Finance chart API via the scheduled GitHub Actions workflow (reit-prices.yml) when accessible; when the sandbox proxy blocks direct access (CONNECT refused, 403 Forbidden — same condition as every Monday run since August 10, 2026), the report uses the committed rw_prices.json snapshot from that workflow.
